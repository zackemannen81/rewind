
# RE:WIND Project Resources

This document outlines the roles and responsibilities for the RE:WIND development team, designed for an AI-augmented workflow.

## Human Roles

- **Lead Designer / Game Director:**
  - Owns the overall creative vision.
  - Responsible for the clarity and detail of the GDD.
  - Defines creative goals for each milestone.

- **Technical Director / System Architect:**
  - Designs the overall software architecture.
  - Creates technical blueprints and API contracts for AI agents.
  - Reviews AI-generated code for quality, performance, and integration.

- **AI-Assisted Developer / System Integrator:**
  - Translates GDD features into precise, technical prompts for AI agents.
  - Reviews, tests, and validates AI-generated code.
  - Integrates AI-generated modules and troubleshoots complex issues.
  - Manually codes the most complex, innovative systems where AI falls short.

- **3D Artist / Sound Designer / Narrative Designer:**
  - Creates and delivers clearly named and structured art, sound, and narrative assets.
  - Works with developers to ensure assets are easily implemented by AI agents.

- **QA Tester:**
  - Identifies bugs in both human and AI-generated code.
  - Provides feedback to refine prompts and improve AI agent performance.

## AI Roles

- **LLM Coding Agents:**
  - Execute well-defined coding tasks based on developer prompts.
  - Generate classes, functions, UI elements, and unit tests.
  - Assist with refactoring and optimization tasks.
